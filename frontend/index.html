What this is

Model Context Protocol (MCP) is an open standard that lets AI assistants connect to external tools and data sources in a consistent way. Instead of building a separate integration for every AI app, developers can create one MCP server that works across any MCP-compatible client.

Connect

Copy the exact setup for the client you use.

ChatGPT

Add to ChatGPT Copies the URL and opens ChatGPT's Plugins page.
  1. In the sidebar, open Plugins, then click Add → Add custom MCP server.
  2. Name it anything.
  3. Under Connection, choose Server URL and paste .
  4. Set Authentication to No authentication (mine doesn't require any).
  5. Tick I understand and want to continue, then click Create as a plugin.
  6. In a chat, click + and pick folio-mcp.

Claude Desktop

  1. Sign in to the desktop app and go to Customize → Connectors. Connectors are shared with Claude.ai.
  2. Click Add → Add custom connector.
  3. Name it folio-mcp and paste as the MCP server URL.
  4. Click Continue. If asked for authentication, choose No sign-in.

Claude.ai

Add to Claude Opens Claude's Add custom connector dialog with the name and URL filled in. Copies the URL as a fallback.
  1. Click Add to Claude. The Add custom connector dialog opens with the name and filled in. Claude shows a "suggested by an external link" notice; that is expected, so just check the URL is this site's.
  2. Or do it by hand: Customize → Connectors → Add → Add custom connector, then paste the URL as the MCP server URL.
  3. Click Continue. If asked for authentication, choose No sign-in (mine doesn't require any).
  4. In a chat, click + → Connectors and turn Folio on.
